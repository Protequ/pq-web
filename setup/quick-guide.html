Protequ Physical Integration Management System
Online setup · ~10 minutes

Get the PQ platform running

Download the installer, run it, and open Protequ in your browser. Docker and all application images are downloaded automatically — no manual configuration.

6 steps · fully automated Windows 10 22H2+ / 11 23H2+ · 64-bit PQ Platform v1.0.0

Installation

Five steps, start to finish. Most of it runs on its own.

1

Download & unblock the installer

Download pq-setup-v*.exe from the GitHub Releases page or from your administrator.

Critical — unblock the file before running it.

Windows blocks executables downloaded from the internet. If it is not unblocked, the installer may fail silently.

Right-click the .exe → Properties → tick ☑ Unblock → OK

Or run: Unblock-File -Path ".\pq-setup-v1.0.0-windows.exe"

2

Run the installer & install the PQ app

Double-click the .exe → click Yes on the UAC prompt. The installer detects Online mode automatically and the default install path is C:\ProgramData\Pq.

This installs the PQ Installer app — a desktop tool you can launch again at any time. It doubles as your updater and adapter installer, so you’ll come back to it to add adapters or upgrade components later.

3

Server components

The installer lists the core services it deploys — PQ Server (API, ABAC engine, message-bus orchestration) plus the infrastructure it runs on: go2rtc, Keycloak, NATS JetStream and PostgreSQL.

Each component has a version selector. When a newer version is available the chip updates so you can pick it; otherwise it stays on latest.

Review the list, then click ► CONTINUE.

4

Adapters

Choose the device integrations to deploy. Tick the adapters you want and untick the ones you don’t.

Search by vendor, name or capability and filter by category — CCTV, access, intrusion or module.

Each adapter has its own version selector. When your selection is ready, click ► INSTALL.

5

Docker Desktop — click “Skip”

If Docker is not installed, the installer downloads and installs it. After install, Docker Desktop shows a sign-in screen.

Click “Skip” in the top-right corner.

You do not need a Docker account. Do not close Docker Desktop — the installer needs it running.

Once Docker is running, deployment proceeds automatically:

StageDuration
Check prerequisites~2 s
Install Docker (if needed)2–5 min
Clean up previous installation~5 s
Pull Docker images (repo.protequ.com)3–10 min
Deploy application~30 s
Health check~30 s
6

Done!

Click ↗ Open or go to https://localhost:5443

The browser may show a certificate warning — click Advanced → Proceed (self-signed cert).

Default loginadmin / admin

Common issues and how to resolve them.

ProblemSolution

“System requirements not met”Update Windows to 22H2+ (Win 10) or 23H2+ (Win 11)
Docker not found after installReboot the PC, re-run the installer
Docker login blocks progressClick Skip (top-right)
Containers fail to startEnsure Docker Desktop is running → ► Retry
